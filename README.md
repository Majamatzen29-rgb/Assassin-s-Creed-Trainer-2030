## 📌 Overview

Assassin's Creed Trainer 2030 is a community-made game trainer project featuring a range of gameplay options, including combat enhancements, resource management, progression controls, teleportation, and world settings.

Designed with configurable hotkeys, the project aims to provide convenient access to supported trainer features while playing.

> **Please note:** Feature availability and compatibility depend on the actual build and supported game version.

## 🕹️ How to Use

### Combat Features
Activate the desired combat option using its assigned hotkey. Test features individually to confirm that they work as expected.

### Abilities & Resources
Enable the appropriate option for adrenaline, rations, throwables, oxygen, or skill cooldowns. Monitor the corresponding in-game resource or ability.

### Experience & Mastery
Use the assigned EXP or mastery hotkeys. For editable values, follow the controls provided by the trainer interface.

### Location & Teleportation
1. Navigate to a suitable in-game location.
2. Activate **Save Location**.
3. Move to another location.
4. Activate **Teleport to Saved Location**.
5. To test marker teleportation, place a marker on the in-game map before activating the relevant feature.

### Time & Game Speed
Use the assigned hotkeys to test daytime controls and game speed. Extreme speed settings may cause unexpected behavior.

## 🔧 Troubleshooting

**The trainer won't launch**
- Confirm that the download is complete.
- Check the required runtime components.
- Review security software alerts if the executable is blocked.

**Hotkeys aren't responding**
- Confirm that the trainer is running.
- Check the assigned key bindings.
- Verify that your keyboard has a working numeric keypad.
- Confirm compatibility with the installed game version.

**A feature isn't working**
- Test one feature at a time.
- Restart the trainer and game.
- Check for compatibility updates.

**The game crashes**
- Disable the last feature you activated.
- Restart the game.
- Restore a backup save if necessary.
